# CLYVEXA — Professional AI & Software Solutions

A professional static website for CLYVEXA, an AI and software solutions company.

## Pages

| Page | File | Content |
|------|------|---------|
| Home | `index.html` | Hero, Services, Stats, Why Choose Us, Age Counter, Industries, CTA |
| About | `about.html` | Mission, Vision, Values, Team |
| Services | `services.html` | 6 services with pricing, process steps |
| Contact | `contact.html` | Phone, email, address, hours, FAQ |
| Privacy | `privacy.html` | Privacy policy |
| Terms | `terms.html` | Terms of service |

## Features

- **Website Age Counter** — live clock counting from February 16, 2026
- **Splash Screen** — animated intro (first visit only)
- **Dark/Light Mode** — toggle with persistence
- **Scroll Animations** — Intersection Observer based
- **Mobile Responsive** — works on all screen sizes
- **No backend required** — pure static HTML/CSS/JS
